02 // SAFE TOOLKIT

صندوق الأدوات الذكي

أدوات توعوية تعمل داخل متصفحك؛ لا تنفّذ فحصًا هجوميًا ولا ترسل بياناتك إلى خادم.

↗TOOL / 01

مراجعة رابط

افحص شكل الرابط بحثًا عن مؤشرات مريبة، دون فتحه.

النتيجة تظهر هنا. لا تفتح أي رابط مشبوه.

هذه مراجعة أولية وليست ضمانًا لسلامة الموقع.

▦TOOL / 02

قائمة فحص كلمة المرور

قيّم خصائص كلمة مرورك محليًا. لا تكتب كلمة مرور حقيقية تستخدمها.

لن يتم حفظ النص أو إرساله.

استخدم مدير كلمات مرور ومصادقة متعددة العوامل.

كيف تتعرف على التصيّد؟

انتبه للاستعجال المصطنع، وعناوين المرسلين الغريبة، وطلبات كلمات المرور أو رموز التحقق.

أساسيات كلمات المرور

أنشئ كلمة مرور طويلة وفريدة لكل حساب، وتجنّب المعلومات الشخصية الشائعة.

مدير كلمات المرور يساعدك على إنشاء كلمات مختلفة وتخزينها. فعّل المصادقة متعددة العوامل حيثما توفرت.
