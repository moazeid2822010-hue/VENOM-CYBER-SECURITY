# VENOM CYBER SECURITY

A responsive Arabic/English cybersecurity awareness website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive neon cyber UI
- `script.js` — language toggle, welcome speech, educational URL review, sample password checklist, article expanders

## Run locally
Open `index.html` in a modern browser.

## Publish using GitHub from your phone
1. Sign in to GitHub and create a new **public repository** (for example `venom-cyber-security`).
2. Open the repository, choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` (or upload the ZIP and extract it before uploading).
4. Commit the files to the `main` branch.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site; the URL appears in the Pages section.

## Safety notes
- The URL review is a basic client-side heuristic, not a reputation service or a guarantee of safety.
- The password checker is local and clears the input after checking. Use only a sample password, never a real credential.
- This is an educational demo, not a penetration-testing service.
- Speech synthesis depends on browser/device support.
